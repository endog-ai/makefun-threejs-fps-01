WHITEOUT is a round-based tactical FPS at Halcyon Station, an Antarctic research outpost under a polar-night aurora. Two teams fight over the THAW CORE: plant it at the Observatory Dome or the Fuel Depot, defend it, or defuse it — first to 5 rounds takes the match across 3 lanes (Glacier Path, Crevasse Bridge, Service Corridor). The signature WHITEOUT blizzard rolls in every ~25 seconds for ~5 seconds: fog thickens to ~6 m visibility, movement slows, bots hold and repath. Built by an AI agent for make.fun's "Make the best three.js tactical FPS" bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
```
